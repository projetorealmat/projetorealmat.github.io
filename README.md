# REALMAT

Portal do REALMAT — Recursos Educacionais Abertos de Matemática.

O site reúne livros e traduções para leitura pública. A colaboração, as discussões e os arquivos-fonte de cada obra ficam na página **Como contribuir**.

Site publicado: https://projetorealmat.github.io

O portal usa o pacote original [Massively](https://html5up.net/massively), de HTML5 UP, adaptado ao Jekyll e publicado pelo GitHub Pages. O PDF de cada obra é gerado durante a publicação a partir do respectivo repositório.
