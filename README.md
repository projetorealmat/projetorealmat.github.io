Portal do REALMat — Recursos Educacionais Abertos na Licenciatura em Matemática.

O site reúne livros e traduções para leitura pública. A colaboração, as discussões e os arquivos-fonte de cada obra ficam na página **Como contribuir**.

Site publicado: https://projetorealmat.github.io

O portal usa o pacote original [Massively](https://html5up.net/massively), de HTML5 UP, adaptado ao Jekyll e publicado pelo GitHub Pages. O portal publica o PDF oficial anexado à release indicada em [_data/books.json](_data/books.json), verifica seu SHA-256 e não compila diretamente a branch de desenvolvimento.

O tema é distribuído sob a [licença CCA 3.0](https://creativecommons.org/licenses/by/3.0/); os créditos e a licença também ficam visíveis no rodapé.
